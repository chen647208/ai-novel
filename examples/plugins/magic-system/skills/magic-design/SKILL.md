# 魔法体系设计方法论

## 三件套（缺一即退回）

1. 来源：力量从哪来。缺来源的魔法等于机械降神。
2. 代价：每次施法支付什么。代价模糊则战力膨胀。
3. 限制：明确不能做什么。限制越具体，剧情越好写。

## 一致性检查

- 同一体系内法术代价量级可比，禁双标。
- 新法术必须回答：谁教的、在哪学的、代价谁付。

## 操作流程

1. 先定限制，再定代价，最后定来源。
2. 为体系写 3 条铁律（绝不打破的规则）。
3. 登记到 magic-system 卡；法术挂 magic-spell 卡并关联所属体系。
