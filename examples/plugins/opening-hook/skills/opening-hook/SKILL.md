# 开篇钩子方法论

## 首段三问

1. 谁在做什么，遇到什么麻烦？（场景与冲突）
2. 读者为什么要看下去？（悬念或反差）
3. 与主线什么关系？（不跑题）

## 三章节奏

- 第一章：立主角与处境，抛出第一个麻烦。
- 第二章：主角做选择，付出第一次代价。
- 第三章：能力/关系转弯，留下大期待。

## 反例

- 大段世界观介绍无人物行动。
- 主角全程被动，冲突靠旁白交代。
