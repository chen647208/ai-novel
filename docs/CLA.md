## 如何签署

本项目使用 **cla-assistant** 在 Pull Request 上自动校验签署状态：

1. 首次向本项目提交 Pull Request 时，cla-assistant 机器人会在评论中给出签署链接；
2. 点击链接、以 GitHub 账号确认同意本 CLA 即可（个人贡献者）；
3. 代表公司贡献的，按提示完成实体签署。

签署一次后，你对本项目的后续贡献自动覆盖，无需重复签署。
