# 伏笔回收方法论

## 健康度判据
- 悬置 10 章以上的伏笔进入危险区：读者记忆成本随章节指数上升。
- 每条伏笔回收前需要 1~2 次「提醒」（无意提及，非重复叙述）。
- 高重要度伏笔必须「三次露出」：埋设、提醒、回收。

## 回收方式排序（由强到弱）
1. 反转式：伏笔的真相与读者预期相反。
2. 呼应式：回收时激活埋设时的完整场景/台词。
3. 复利式：一次回收同时解释两条以上伏笔。
4. 平收：如实兑现（仅低重要度伏笔可用）。

## 操作流程
1. 用 core.index.query 的 foreshadow 查询列出全部未回收伏笔及悬置时长。
2. 标记超期条目，按重要度排序。
3. 为每条选择回收章位：优先塞进已有高潮场景，不专门开新章。
4. 输出回收方案：章位、方式、提醒位置（在回收前 1~2 章插入）。
