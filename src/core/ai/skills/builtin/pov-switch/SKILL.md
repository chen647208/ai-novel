# POV 转换方法论

## 切换节奏
1. 章内不切视角（新手铁律）；章间切换优先，场景切换次之。
2. 同一角色连续 POV 不超过 3 章，除非该线处于高潮推进期。
3. 切换后 300 字内必须重立「我是谁/我在哪/我要什么」。

## 信息差管理
- 读者视角池 = 各 POV 已知信息的并集；悬念来自「读者知道 A 不知道 B」。
- 避免「信息倒灌」：A 视角已揭露的真相，不要在 B 视角重新完整叙述一遍，只写 B 的反应。

## 声音区分
每个 POV 三件套：
1. 词汇域（文人 vs 武人 vs 市井）。
2. 比喻来源（出身决定他用什么打比方）。
3. 叙事重心（同一事件，不同 POV 关心的细节不同）。

## 自查
切换处问三个问题：读者会暂时困惑吗？两个视角的声音能否互换而不违和？这一章的信息量配得上一次切换吗？
